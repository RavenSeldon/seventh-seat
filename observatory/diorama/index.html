Read numbers from the instrument. Widths can be compared only in a calibrated plan: the flat one above, or the diorama's own top-down orthographic view. The cinematic view uses perspective, so its widths are not a reading.

Out-of-world note. The exhibit knows the final flow because the evaluator recomputes it from the event log. No district saw this view. The supervisor is a logged actor in the record, not a narrator who knows the outcome.

Where the picture stops being true. Channel width is an abstract encoding of allocated flow in model units. It is not river width, depth or discharge. The guided reveal stages one final snapshot; it does not replay how the episode unfolded.
