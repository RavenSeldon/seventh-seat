# Empirical manuscript

This JSON contains the reviewed 96-episode results and interpretation, including the post-collection event census. The final PDF and editable DOCX are release assets at https://github.com/RavenSeldon/seventh-seat/releases/tag/research-2026-11-07.

Build with report/working/build_manuscript.py --data report/final/manuscript.json --output PATH.docx using the retained official template. The general assembler produces a starting draft; it does not recreate the subsequent scientific prose review. The PDF uses six main pages plus two reference/appendix pages and a 194-word abstract. All pages were visually reviewed. Publication does not constitute sprint submission.
